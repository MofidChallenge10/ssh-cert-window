# Contributing 🤝

1. Open an issue describing the use case and expected behavior.
2. Keep changes focused and preserve backward-compatible CLI output where practical.
3. Add or update tests for every behavior change.
4. Run the test command in the README and ensure CI passes.
5. Do not commit credentials, private logs, generated artifacts, or unrelated formatting changes.

By contributing, you agree that your contributions are provided under the repository MIT license.
